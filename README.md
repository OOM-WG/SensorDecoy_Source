# ColorOS 满血核心源码

> 修改内容：全部解密，去掉脏话、隐私信息、付费验证、冲突检测

我很痛恨没有任何技术还要窃取他人技术的人，故解密开源，以后也会同步更新，除非这种圈钱的垃圾模块停更

> 这种垃圾模块还是非常不建议使用的，把手机搞坏了还不知道怎么恢复就老实了

使用满血核心会造成以下后果:

- 性能异常，卸载无法恢复（对系统造成了可逆的损害，但是单纯卸载模块无法恢复）
- 被释放垃圾文件，环境 100% 泄露（使用环境模块无法解决）
- 其他操作也会造成环境 100% 泄露（使用环境模块无法解决）

> [!tip]
> 如果系统异常可以尝试清理系统缓存，没有问题卸载了就不用管了
>
> 如果不知道怎么清理，可以使用 [SSU](https://ssu.oom-wg.dev) 来清理，里面有专门为这个垃圾模块而写的清理功能
>
> 卸载满血核心后需要**重启两次**！！！否则还是会造成环境 100% 泄露
